# 리온이 배구

피카츄 배구 웹 버전을 기반으로, 참가자가 봇 코드를 작성해 붙일 수 있도록 개조한
**2026 성균관대학교 × 한양대학교 CSE 교류전 AI 부문 대회 버전**입니다.

## 가이드

참가자 안내, 봇 코드 작성 규약, 대회 규칙 등 실행·활용 방법은 별도 가이드 문서에서
확인할 수 있습니다.

- **가이드 문서**: https://shaims.vercel.app/
  - 팀명과 별도 안내된 비밀번호로 로그인 후 **[가이드]** 메뉴를 확인해주세요.
